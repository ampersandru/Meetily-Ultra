# Meetily Ultra releases

Ultra's default branch is `codex/meetily-ultra`. PR38's original `codex/combined-audio-speakers-labs` branch remains unchanged. Ultra has bundle ID `com.ampersandru.meetily-ultra`, binary `meetily-ultra`, version 0.3.0, and separate macOS/fallback data directory `Meetily Ultra`. Portable Windows data stays beside Ultra's executable. Copyrights and model download origins are retained.

The editable vector logo is `frontend/public/ultra-mark.svg`; regenerate desktop icons with `cd frontend && pnpm exec tauri icon public/ultra-mark.svg --output src-tauri/icons`. Sidebar, About, app/window, tray, toast and installer branding use Ultra assets. The old upstream updater is not registered or queried. About and the tray direct users to Ultra's release downloads.

Use the manually dispatched **Release Meetily Ultra** workflow. It runs isolated frontend tests, production build and TypeScript checks, plus native Windows tests and macOS capture-worker/source-continuity tests. Each platform builds from the selected commit; publication requires every build and validation job to pass. The workflow checks checksums and publishes one initially drafted release only after all three installers exist. It refuses to overwrite an existing release version.

Windows: Visual Studio C++ Build Tools, Ninja, pinned LLVM 18 bootstrap, Rust 1.97.1+, Node 24 and pnpm 11.9.0. Run `./frontend/scripts/build-ultra-windows.ps1`. It builds the CPU helper and app, stages the hash-verified ONNX/DirectML runtime, checks Microsoft's Visual C++ redistributable signature, then bundles NSIS. Verification tests the archive and compares packaged application, sidecars and runtimes to the build outputs, followed by sidecar smoke tests.

macOS: run `bash frontend/scripts/build-ultra-macos.sh aarch64-apple-darwin` on Apple Silicon, or pass `x86_64-apple-darwin` on Intel. Install OpenSSL 3 headers, Xcode command-line tools and the same Rust/Node/pnpm versions. Native dependencies outside system frameworks are copied into the bundle and their install names rewritten before ad-hoc signing. This avoids relying on the builder's Homebrew libraries at runtime. The script checks signatures, architecture, permissions, bundled resources, sidecar behavior and DMG integrity. Builds require macOS 14.2 or later; the CI runner is macOS 15.

Installers are not Windows Authenticode signed or Apple Developer ID notarized. No upstream signing secrets are copied. Automatic update artifacts/feeds are intentionally disabled for this initial release. Verification is build/package qualification, not a physical microphone/system-audio test, voice-match accuracy benchmark, or proof of capture quality on every computer. Model/audio-dependent ignored tests must be reported separately.
